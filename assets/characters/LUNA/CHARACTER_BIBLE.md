## 二、外貌特征（Character DNA — 锁定不可变）

### 2.1 脸型
```
形状:      鹅蛋脸 (oval) — 不是瓜子脸/圆脸/方脸
下颌线:    柔和曲线 — 不能是尖下巴
颧骨:      不突出，线条柔和
额头:      适中高度，不宽不窄
三庭五眼:  比例标准
正面印象:   温柔、亲切、像邻家女生
```

### 2.2 眼睛
```
类型:      大而柔和 — 不是圆眼/细长眼
形状:      月牙形 — 眼尾自然微弯上翘
双眼皮:    自然双眼皮，不宽
眼距:      标准（一眼宽度）
眼神:      温暖、有光、带着笑意
颜色:      深棕色
睫毛:      自然长度，不浓密
```

### 2.3 眉毛
```
类型:      自然弧度
粗细:      中等，不画浓眉
颜色:      深棕色（比发色稍浅）
眉峰:      柔和，不锐利
眉头:      略粗，自然过渡
```

### 2.4 鼻子
```
类型:      小巧直鼻
鼻梁:      高度适中
鼻头:      圆润小巧
鼻翼:      不宽
侧面:      线条柔和
```

### 2.5 嘴巴
```
类型:      自然微笑唇
嘴角:      微微上扬（天生的温暖感）
厚度:      中等
颜色:      暖粉色
特征:      不笑时也有淡淡的亲和力
```

### 2.6 肤色
```
基调:      暖白皮
质感:      柔和、健康
没有:      雀斑/痣（除非真人本人有）
```

### 2.7 发型
```
颜色:      自然黑色（阳光下泛深棕色）
长度:      过肩长发，到胸口位置
刘海:      空气刘海，向左偏分
质感:      柔顺，发尾轻微自然卷
发量:      中等偏多
扎发:      偶尔低马尾（毕业生形态）
```

### 2.8 耳朵
```
大小:      中等
形状:      标准
露出:      刘海和侧发半遮
```

### 2.9 身材
```
身高:      160cm（像素游戏比例）
体型:      纤细，匀称
头身比:    1:6.5（头35% 身体65%）
肩宽:      适中偏窄
```

### 2.10 手部
```
大小:      小巧
手指:      纤细
特征:      拿麦克风时手指自然弯曲
```

## 六、禁止事项

```
❌ 重新设计脸部
❌ 改变脸型（鹅蛋脸不能变瓜子脸）
❌ 改变发型/发色/刘海方向
❌ 改变眼睛形状（月牙眼不能变圆眼）
❌ 改变嘴角弧度
❌ AI 美化（瘦脸/大眼/美白/磨皮）
❌ 生成陌生人物
❌ 改变年龄感（不能变小孩/变老）
❌ AI 幻想风格（过度华丽/翅膀/魔法特效）
❌ 不同帧之间角色不一致
❌ 经典8-bit大头小人比例
```

## 七、素材验收标准

生成后逐项检查：

- [ ] 正面照对比：一眼能认出是同一人
- [ ] 眼睛：月牙弯眼，弧度一致
- [ ] 嘴巴：嘴角自然上扬
- [ ] 发型：黑色过肩长发，左分空气刘海
- [ ] 脸型：鹅蛋脸，柔和下颌线
- [ ] 肤色：暖白皮
- [ ] 三形态五官一致
- [ ] 像素风格符合 Nintendo cozy RPG
- [ ] 动画帧之间角色一致
- [ ] 透明背景无白边
- [ ] 文件命名符合规范
- [ ] 尺寸符合规范（128×128 或 64×64）
