# LUNA 角色素材规范 V2.0

> 与 `ART_PRODUCTION_GUIDE.md` 配套使用。
> 本文件定义素材的技术规格和目录结构；
> ART_PRODUCTION_GUIDE.md 定义 AI 生成 Prompt。

---

## ⚠️ 角色一致性规则（Character Consistency Rule）

```
任何新素材必须基于 LUNA-001 角色档案。

禁止重新设计角色。
禁止生成不同脸。
禁止替换发型。
禁止改变眼镜。
禁止改变五官比例。

所有动画必须来自同一个角色模型。

如果发现素材不符合 → 拒绝接入 → 要求重新生成。
```

## Sprite 精灵图规格

### 通用参数

| 参数 | 值 |
|------|-----|
| 美术风格 | Stardew Valley / Nintendo cozy pixel art |
| 角色画布 | 128×128 px |
| 表情画布 | 64×64 px |
| 像素滤镜 | nearest-neighbor（禁止平滑） |
| 背景 | 透明 PNG |
| 格式 | PNG-24 (带 Alpha 通道) |

### 各动画帧规格

| 动画 | 文件名 | 帧数 | 帧尺寸 | FPS | 循环 |
|------|--------|------|--------|-----|------|
| 待机 | `idle.png` | 8 | 128×128 | 8 | ✅ |
| 唱歌 | `sing.png` | 12 | 128×128 | 10 | ✅ |
| 跳舞 | `dance.png` | 16 | 128×128 | 12 | ✅ |
| 开心 | `happy.png` | 12 | 128×128 | 10 | ✅ |
| 谢幕 | `bow.png` | 8 | 128×128 | 6 | ❌ (停在最后一帧) |
| 表情 | `emotion.png` | 6 | 64×64 | 4 | ❌ (按需切换) |

### 精灵图布局

每张精灵图为水平排列的一行帧：

```
┌────┬────┬────┬────┬────┬────┬────┬────┐
│ F0 │ F1 │ F2 │ F3 │ F4 │ F5 │ F6 │ F7 │  ← idle (8帧)
└────┴────┴────┴────┴────┴────┴────┴────┘
|<-------------- 128×8 = 1024px --------->|
```

## 配套 JSON 配置模板

每个 `*.png` 配一个同名 `*.json`：

```json
{
  "name": "idle",
  "file": "idle.png",
  "frameWidth": 128,
  "frameHeight": 128,
  "frames": 8,
  "fps": 8,
  "loop": true,
  "description": "LUNA graduation idle breathing animation"
}
```

## 素材验收标准

1. **角色一致性**：三个形态的五官、发型、眼镜完全一致
2. **像素风格**：nearest-neighbor 缩放，无模糊
3. **动画流畅**：帧间过渡自然，循环无缝
4. **透明背景**：PNG Alpha 通道干净无白边
5. **文件规范**：命名、尺寸、帧数符合本规范
